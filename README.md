# ⚡ 에너지 전환의 경제적 임계점 분석
> **RE100 vs CF100: AI 산업 성장과 에너지 위기 속 최적의 대응을 위한 최적 에너지 포트폴리오 실증 분석**

## 🎯 Project Objective
신재생에너지 전환 초기 발생하는 경제적 충격을 원자력(CF100)이 얼마나 완화하는지 **비선형 임계점 모델**을 통해 규명합니다.

## 🛠 Tech Stack
- **Language:** Python 3.x
- **Libraries:** Pandas, WBGAPI(World Bank Data Access), Openpyxl, Scikit-learn
- **Data Sources:** Our World in Data (Energy), World Bank (Economy)

## 📊 Key Methodology
1. **Multi-Source Collection:** API를 통한 실시간 에너지 및 경제 지표 통합
2. **Data Cleaning:** 결측치 제거를 통한 고순도 분석 데이터셋 구축
3. **Threshold Analysis:** 비선형 회귀를 이용한 경제적 비용 변곡점 도출
